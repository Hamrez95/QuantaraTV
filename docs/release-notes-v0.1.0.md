# Quantara Vision v0.1.0

First usable implementation of the Design Freeze v1.0 as a single Pine Script v6 indicator.

## Included

- Confirmed structure, deterministic clustered S/R, pivot trendlines/channel, contextual price action, volume/volatility, VWAP, and session logic.
- Five-state confirmed MTF strip using the documented non-repainting HTF pattern.
- Crypto leadership/rotation, simplified Forex strength, intermarket, slow economic, and stock financial context with resource profiles.
- Three manual event slots with forecast/previous notes, blackout behavior, and observed post-event reaction.
- Explainable 0–100 score, persistent signal lifecycle, frozen risk plan, approximate sizing, JSON/readable alerts, and configured-symbol radar.
- Separate validation strategy, CI, full settings/limitations documentation, Design Freeze map, repaint checklist, and test matrix.

## Verification state

Local and GitHub static checks are required to pass. TradingView compilation remains a separate evidence gate: both Pine files must be added to a chart in an authenticated Pine Editor before the release is described as compiler-verified.

## Known limitations

Pine cannot fetch arbitrary live news, execute orders, provide centralized Forex volume, guarantee pixel-perfect panels, or scan an unlimited market. Context datasets depend on the symbols and entitlements available in the user's TradingView account.
