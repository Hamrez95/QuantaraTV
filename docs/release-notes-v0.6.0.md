# Quantara Vision v0.6.0

## Trader-first workflow clarity

- `READINESS` shows five independent gates: Context, Location, Trigger, Economics, and Safety.
- Quality A/B is transparent evidence classification, not a profitability claim.
- Finished model plans can remain as a small number of faded archived lines for chart review.
- Runtime alerts can be filtered to the workflow that matters right now: scan, manage, risk, or all.

## Honest boundary

Archived plans and alerts are based on chart data. They cannot verify broker/exchange fills, manage an order, or retrieve arbitrary live news.
